# Безопасность

Не публикуйте сведения об уязвимостях и реальные пользовательские обращения в публичных Issues или PR.

Предпочтительный путь: приватное сообщение мейнтейнеру через GitHub Security Advisories / Private Vulnerability Reporting, если функция доступна. Не включайте действующие ключи API и личные идентификаторы.

Вопросы и ответы хранятся только в локальной закрытой SQLite; технические ADR и статусы не содержат обращения. Репозиторий публичный; база данных, токены Telegram и почты, owner-only Notify и личные данные — нет.

Утверждение ответа владельцем для точной версии черновика обязательно. Публичный API не может обходить этот контроль. Неоднозначную доставку нельзя автоматически повторять.
