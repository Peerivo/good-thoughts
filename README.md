# Фабрика добрых мыслей / Good Thoughts Factory

Отдельный проект Peerivo: React-сайт + Telegram-бот + локальная SQLite-очередь вопросов и ответов.
Утверждённый адрес: https://dobro.peerivo.net (DNS и HTTPS настроены).

**Инкремент 1**: безопасное сохранение, подтверждение email, асинхронная очередь. Автоматические ответы и Telegram включаются только после ввода соответствующих секретов и проверок. Никакого хранения пользовательских обращений в GitHub или Mira Vault: там находятся только инженерные статусы и проектные решения.

Команды: `npm ci`, `npm test`, `npm run build`, `npm run start`.
Настройки см. `.env.example`, архитектуру — `docs/ARCHITECTURE.md`.

Жизненный цикл: обращение с сайта → email с кодом → подтверждение → очередь → черновик → индивидуальное утверждение владельцем → email. Telegram: личный чат → подтверждённый канал по Telegram update → очередь → ответ в тот же чат. Без работающей исходящей почты приём email-обращений заблокирован честным сообщением, чтобы не обещать недоставляемое подтверждение.

Принципы безопасности: не медицинский/психотерапевтический сервис, минимум персональных данных, лимиты отправки, удаление старых записей, ограничение доступа к очереди, отдельные сервисные секреты.

## Проверка владельцем перед отправкой

При поступлении подтверждённого вопроса формируется уведомление и очередь. ИИ/агент может подготовить черновик, но **никогда не утверждает его за владельца**. Только отдельный owner-approved exact draft version может быть отправлен. Рабочая схема: /api/internal/draft -> /api/internal/approve -> /api/internal/deliver. Старый /api/internal/answer отключён (HTTP 410).

Публичный репозиторий доступен по MIT. Внешние изменения через Pull Requests. Правила CONTRIBUTING.md и SECURITY.md. Пользовательские вопросы, ответы и email не сохраняются в GitHub/Vault.

Оригинальный логотип ДМ на белом фоне: \`web/public/dm-logo.png\` (640×360); иконка: \`web/public/dm-icon.png\` (512×512, в том числе favicon). Ссылка на проект в главном меню peerivo.net откладывается до завершения и приёмки проекта, как распорядился владелец.
