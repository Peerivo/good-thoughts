# Вклад в «Фабрику добрых мыслей»

Спасибо за желание улучшить проект. Исходный код открыт по лицензии MIT.

1. Создайте fork репозитория и отдельную ветку от актуального main.
2. Для изменения поведения сначала добавьте тест; выполните npm ci, npm test и npm run build.
3. Откройте Pull Request с описанием изменений и результатами проверок. Production деплоит только владелец.
4. Перед PR убедитесь, что нет секретов, личных сообщений, email, Telegram chat ID, SQLite, логов или персональных данных. Не прикладывайте реальные обращения даже как примеры тестов.
5. Никакой пользовательский ответ не может быть отправлен без отдельного явного решения владельца для точной версии черновика. Изменения, ослабляющие эту проверку, не принимаются.
6. Пишите инклюзивные, уважительные тексты. Избегайте медицинских обещаний, манипуляций и токсичной позитивности.

### Технический стек
Node.js 24+, React/Vite, встроенный SQLite; запуск npm run check.
Настройки берите из .env.example; не сохраняйте файлы .env в Git.
Не меняйте инфраструктуру Peerivo и другие репозитории в PR к этому проекту.
